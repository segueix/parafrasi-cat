# Corpus de validació

Frases i textos que es fan servir en els tests automatitzats per comprovar
que el motor respecta els invariants de contingut: dates, xifres, noms
propis, números romans, citacions i text entre cometes.

`frases_prova.txt` conté una frase per línia. Els tests processen cada frase
amb totes les regles disponibles i comproven que cap fragment protegit no
s'altera.
